Our institute pipeline is currently a static directory of names and links. Outbound IQ turns each institution into a researched, scored, and pitch-ready opportunity, so the team spends its time in conversations instead of open browser tabs. This session walks through what the tool does today, how it works, and what's coming next.

What you'll see

01

Research

An institution's programs, relevant courses, labs and hardware facilities, faculty interests, industry partners, and decision-makers, pulled from official sources.

02

Scoring

An outreach-fit score that shows its reasons, what evidence supports it, and what is still unknown, instead of a bare number.

03

Pitch

A reviewable report and a curriculum-fit pitch deck for that institution, with sources cited and a shareable link.

Key takeaways

  • See how a raw institute name becomes a qualified, evidence-backed lead.
  • See how the fit score separates curriculum fit from buying readiness.
  • See how the same evidence drives both the report and the pitch deck, so nothing in a pitch is unsupported.

Where the tool stands

A working MVP exists with institute discovery, basic research, and a three-slide deck. In progress: a versioned evidence model, an explainable fit score, citations throughout, and a shareable report view.
