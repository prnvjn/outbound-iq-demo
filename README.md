# LabLaunch Demo

A responsive, static one-page site for the LabLaunch internal demo.

LabLaunch, by MakeGPT, is the internal sales and customer-success tool for selling MakeGPT's lab program to universities.

Live GitHub Pages URL: https://prnvjn.github.io/outbound-iq-demo/

Design estimates: the original display typeface was unavailable, so headings use a system sans-serif at similar weights and sizes. The hero illustration is an original neutral SVG. Card padding, 14px corner radius, subtle shadow, and the 880px desktop content width are close visual estimates based on the source page.
